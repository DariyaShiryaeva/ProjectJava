Общее описание проекта

Это учебный проект на Spring Boot с использованием Spring Data JPA и Thymeleaf. Проект реализует простую систему управления заказами: пользователи могут создавать заказы, выбирать продукты и их количество. В базе данных хранятся пользователи (User), продукты (Product), заказы (Order) и позиции заказов (OrderItem). DataLoader загружает пример данных при старте приложения.

Структура проекта

  • controller — контроллеры для обработки HTTP-запросов (UserController, ProductController, OrderController)
  • service — бизнес-логика приложения (CRUD для пользователей, продуктов, заказов)
  • model — сущности JPA (User, Product, Order, OrderItem)
  • repository — интерфейсы Spring Data JPA для работы с базой
  • templates — Thymeleaf-шаблоны для отображения страниц
  • DataLoader — компонент для начальной загрузки данных
