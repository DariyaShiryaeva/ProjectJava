Шаблоны Thymeleaf

Главная Контроллеры Сервисы Модели Репозитории DataLoader

Список пользователей — users/list.html

Отображает таблицу всех пользователей с кнопками Редактировать / Удалить и ссылкой Добавить нового пользователя.

Форма пользователя — users/form.html

Форма для добавления и редактирования пользователя.

Список продуктов — products/list.html

Отображает таблицу продуктов с редактированием и удалением.

Форма продукта — products/form.html

Форма добавления/редактирования продукта.

Список заказов — orders/list.html

Таблица заказов с пользователями, продуктами, количеством, датой, редактированием и удалением.

Форма заказа — orders/form.html

Форма добавления/редактирования заказа с выбором пользователя, продукта и количества.
