# Проект "Система управления заказами"

## Описание

Проект представляет собой **веб-приложение на Spring Boot** для управления пользователями, продуктами и заказами.  
Используется база данных через **Spring Data JPA**, шаблоны отображения — **Thymeleaf**.  

Основные функции:

- CRUD (создание, чтение, обновление, удаление) для пользователей, продуктов и заказов.
- Автоматическая загрузка тестовых данных через **DataLoader** при старте приложения.
- Поддержка нескольких позиций в заказе с расчетом общей суммы.
- Валидация данных на уровне моделей.

## Запуск проекта

1. Клонировать репозиторий:  
```bash
git clone https://github.com/DariyaShiryaeva/ProjectJava.git
```
2. Запустить приложение через Maven или IDE (например, IntelliJ IDEA):
```bash
./mvnw spring-boot:run
```
3. Перейти в браузере по адресу:
```bash
http://localhost:8080
```

## Работа с данными

В приложении реализованы следующие разделы:

- **Пользователи**: `/users`
- **Продукты**: `/products`
- **Заказы**: `/orders`

Доступные операции:

- Добавление новых записей
- Редактирование существующих записей
- Удаление записей
- Просмотр списков с детальной информацией

---

## DataLoader

При запуске приложения автоматически создаются тестовые данные:

- 10 пользователей
- 10 продуктов
- Несколько заказов с разными продуктами и количеством

Это позволяет сразу тестировать функционал приложения без ручного ввода данных через интерфейс.

## Навигация по коду

Структура проекта организована следующим образом:

- `controllers/` — обработка HTTP-запросов и взаимодействие с сервисами
- `services/` — бизнес-логика приложения
- `model/` — JPA-сущности (User, Product, Order, OrderItem)
- `repository/` — интерфейсы Spring Data JPA для работы с БД
- `templates/` — HTML-шаблоны Thymeleaf
- `DataLoader.java` — класс, заполняющий базу данных тестовыми данными при старте приложения
